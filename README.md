# Credit Risk Analysis: Option Care Health (OPCH) LBO First-Lien Term Loan B

**[Read the investment committee memo →](https://anan986.github.io/opch-lbo-credit-analysis/)**

Independent analysis based on public SEC filings and market data, of whether a lender should
participate in the first-lien Term Loan B financing the $5.8bn (enterprise value)
take-private of Option Care Health.

## Recommendation
Do not commit at launch terms. Re-engage if term debt comes down to about $2.9bn (≤ 7.0x).

| Metric | Result |
|---|---|
| Underwriting EBITDA (LTM Jun-26) | $404mm (14% below management) |
| Leverage at close | 7.8x Underwriting EBITDA |
| 7-year probability of default (weighted) | 41% vs 25% limit |
| First-lien recovery (downside) | 53% |
| Maximum supportable term debt | $2.9bn |
